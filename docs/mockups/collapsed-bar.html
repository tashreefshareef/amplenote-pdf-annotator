The same three at 44px · costs a note rewrite

22px is the root problem: it is half a tap target, and the height query already strips the count to make things fit. A collapsed viewer could size its bar the way "Fit to this screen" sizes the open one — the device that collapses writes width / 44 into the tag, so the bar is a comfortable 44px on whatever screen collapsed it (≈8 on this phone, ≈16 on a desktop, which is today's value). The trade is the one you already know: that number is shared, so a viewer collapsed on the phone opens ~89px tall on the desktop until something rewrites it.
